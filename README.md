# saas-launch-playbook

SaaS 产品发布完整指南 —— 给独立开发者 / 一人公司的上线实战手册。

## 包含内容
- `SKILL.md`：三阶段 playbook —— 上线前验证（付费意愿 → 楔子定位 → MVP → 定价）→ 上线周打法 → 上线后 8 周增长；5 大心态转变；14 个死亡陷阱
- `references/checklists.md`：上线前检查清单
- `references/channels.md`：渠道分级与中国渠道适配（V2EX / 即刻 / 小红书 / 少数派等）
- `references/metrics.md`：早期关键指标与健康线

## 用法
把本仓库作为 AI 助手（如 Custom GPT）的知识库，让它按 playbook 帮你做发布规划、卡点诊断或复盘。
