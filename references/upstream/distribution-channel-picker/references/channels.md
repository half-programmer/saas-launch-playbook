# 七个渠道详解

每个渠道：是什么 / 适合谁 / 怎么做 / 起效节奏 / 最常见的坑 / 中国映射。

## 1. SEO 与程序化内容

- **是什么**：针对高购买意向关键词的内容，排名后每天自动带来流量，持续成本接近零，复利最强。
- **适合谁**：用户会主动搜索解决方案的品类（工具、SaaS、B2B）。
- **怎么做**：不做泛泛的 explainer，做帮人做购买决策的内容——竞品替代页（"Alternative to X"）、对比指南、问题导向的 how-to（产品是自然解法）。关键词选"Best content calendar for indie hackers"而不是"What is a content calendar"——前者搜索量小十倍，转化高十倍。
- **起效节奏**：慢（数月），但一旦起来就是睡后流量。
- **坑**：写自嗨的品牌词、追大词；内容不解决购买决策。
- **中国映射**：微信搜一搜 / 百度 SEO、知乎高赞回答、小红书搜索（"小红书 SEO"本质是关键词内容）、少数派。

## 2. 创始人短视频

- **是什么**：创始人真人出镜的 30–90 秒实用短视频。
- **适合谁**：愿意出镜、能把干货讲清楚的创始人；2026 年涨得最快的创始人几乎都是每天出镜的人。
- **怎么做**：每天一条 × 30 天。内容：战术小技巧、带真实数字的建造更新、niche 内的 teardown。**要实用，不要精致**——清晰和持续胜过制作质量。
- **起效节奏**：30 天可见分水岭；研究显示 30 天日更实用视频胜过数月纯文字。
- **坑**：追求剪辑和布光、更新三天就停、讲产品自夸不讲干货。
- **中国映射**：小红书、视频号、B 站、抖音。国内"创始人 IP + 干货口播"是已被验证的范式。

## 3. X / LinkedIn build in public

- **是什么**：公开建造过程，把"做产品的过程"本身变成内容。
- **适合谁**：擅长写、有表达欲的创始人。
- **怎么做**：内容配比 **40% 实战教训 / 30% 实验与结果（带真实数字）/ 20% 产品叙事 / 10% 直接求助**。大多数人做反了：80% 发产品更新，然后奇怪为什么没人互动——没人关心你的产品，人们关心你学到了什么、踩了什么坑。
- **起效节奏**：数周开始有回声，数月复利。
- **坑**：只发产品更新；断更；不敢发数字和失败。
- **中国映射**：即刻（中文 build in public 主阵地）、X（出海/英文受众）、LinkedIn（B2B）、公众号（长文沉淀）。

## 4. 社区营销

- **是什么**：去目标用户已经在的地方，长期提供价值。
- **适合谁**：niche 社区明确的产品。
- **怎么做**：铁律——**先有用 10 次，再提 1 次产品**。Reddit / Indie Hackers / Slack / Discord：发带数字的详细复盘、公开审计自己的流程、好用的模板、认真回答痛点。禁区："Hey I built this, check it out"——最快被无视/封号的方式。先读每个社区的自推广规则。
- **起效节奏**：几周建立信任，一篇爆款帖可抵 Product Hunt 一天。
- **坑**：空降发广告；只在需要时出现。
- **中国映射**：V2EX（国内独立开发者的 Hacker News，技术诚实+数字）、知乎、豆瓣小组、微信群/知识星球、即刻圈子。

## 5. Newsletter 合作

- **是什么**：在调性相符的 newsletter 上做赞助或联合推广。
- **适合谁**：有明确 niche、有一定预算的产品。
- **怎么做**：找读者 = 你的理想客户的 newsletter。**5000 精准订阅胜过 10 万泛粉**，这是作者见过对独立开发者最好的付费渠道。先互动（回复、转发）和主理人建立关系，再谈赞助/互推——读者信任主理人，信任会转移到被推荐的产品上。
- **起效节奏**：谈成即见效，适合发布期脉冲。
- **坑**：只看订阅数不看读者匹配度；群发 cold pitch。
- **中国映射**：公众号互推/转载、知识星球主理人、小报童专栏、播客串台。

## 6. 集成即分发

- **是什么**：把产品做进大平台的应用市场/集成目录，集成行为本身变成被发现机制。
- **适合谁**：能自然长在某个平台生态里的产品（Notion 模板、Slack bot、Shopify 插件等）。
- **怎么做**：做好一个集成，进官方市场。用户在市场里找方案时发现你，平台替你完成信任背书，推荐流量持续且随平台增长而复利。
- **起效节奏**：上架后持续，长尾。
- **坑**：为集成而集成，产品和平台生态无关。
- **中国映射**：微信小程序生态、飞书/钉钉应用市场、Chrome 插件商店（出海）、Shopify（出海电商）。

## 7. 客户转介绍

- **是什么**：让付费用户替你分发：推荐计划、affiliate、带真实结果的 testimonial 墙、有数字的案例。
- **适合谁**：已经有付费用户、用户确实有 aha 时刻的产品。
- **怎么做**：顺序不能反——**先交付真实价值，等用户过了 aha 时刻再开口**。推荐机制要简单，激励要明确。大多数创始人开口太早。
- **起效节奏**：有第一批满意用户后启动，peer validation 转化高于一切营销文案。
- **坑**：产品还没让人爽就求转发；推荐流程复杂。
- **中国映射**：分销返佣（小报童/知识星球模式）、老带新优惠、用户案例投稿。

## 附：开源分发（技术型创始人的专属通道）

- 开源一个**真正解决独立问题**的好工具（不是故意阉割的付费版），开发者用了就信了，付费版承接信任。
- 开源项目既是产品也是分发机制，社区 adoption 抵得上几万美元的付费投放。
- 在开发者工具赛道，不成比例的高成功率产品都是从开源起家的。
