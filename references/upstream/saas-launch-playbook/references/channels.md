# Channels：平台分级、排序与中国渠道适配

## 平台分级（2026）

| 平台 | 适合 | 能期待什么 | 投入 |
|---|---|---|---|
| Product Hunt | 曝光 spike + 外链 | 上线日大流量、转化一般 | 高 |
| Hacker News（Show HN） | 技术型产品 | 反馈 brutal，偶尔爆量 | 中 |
| Indie Hackers |  bootstrapped SaaS、透明帖 | 创始人受众，慢热 | 中 |
| BetaList | 上线前攒等待名单 | 提前几周的早期用户 | 低 |
| Uneed / Microlaunch / Fazier | 第二、第三上线日 | 小 spike，竞争温和 | 低 |
| Peerlist / DevHunt | 面向开发者的工具 | 精准的开发者目光 | 低 |
| There's An AI For That | AI 产品 | 真 AI 工具才有分类流量 | 低 |
| AppSumo | 终身买断冲收入 | 真金白银，长期单位经济可疑 | 高 |
| G2 / Capterra / GetApp | B2B 评价存在感 | 慢积累的信任信号，非 spike | 中 |
| SaaSHub / AlternativeTo | "Alternative to X" 搜索流量 | 高意向的长尾推荐 | 低 |

## 排序（比数量重要）

1. **上线前几周**：BetaList + 等待名单。
2. **上线日**：Product Hunt + 社区 + 邮件，全部协调在同一天。**六个渠道分三周 = 六个水花；压缩到一天 = 一个自我增强的 spike。**
3. **上线周**：小平台分散到各天，每天都是一个新的发帖理由。
4. **之后几个月**：目录分批提交，50–100 个。这是 SEO 基建。只选有真实 Domain Rating、真人会逛的目录——2000 多个目录里大部分是爬虫垃圾。

## 两个提醒

- 别押宝 Product Hunt 一家：复盘里真实客户多来自个人 outreach、小众社区和 Reddit，PH 给的是虚荣指标 + 外链。它是渠道，不是战略。
- HN 奖励坦诚、惩罚包装： plain "Show HN: [thing], [一句话]" + 诚实的"为什么做、有什么局限"的首评，胜过任何 polished pitch。

## 中国渠道适配（本地化补充，原指南未覆盖）

Product Hunt / HN 对国内独立开发者的问题：时差（12:01 AM Pacific = 北京时间下午 3 点，守评论区要熬夜到凌晨）、受众错位（英文区用户 ≠ 你的中文 ICP）。建议把"上线日渠道栈"按你的 ICP 所在地重排：

| 渠道 | 对应打法 |
|---|---|
| V2EX（分享创造 / 酷工作） | 国内独立开发者的 Show HN。帖子要技术诚实，带数字和踩坑，不要营销腔 |
| 即刻 | build in public 中文主阵地之一，持续更新动态攒关注 |
| 小红书 | 非技术型产品（效率工具、副业、AI 应用）的冷启动利器；真人出镜/录屏演示 > 图文广告 |
| 少数派 | 效率工具类产品的长尾 SEO + 高质量早期用户 |
| 公众号 / 视频号 / Bilibili | 中文 SEO 与信任基建，对应原指南里的"问题型文章" |
| 微信群 / 知识星球 / Discord 中文群 | 对应"混进 ICP 所在的社区"，先贡献再索取 |
| App Store / 微信小程序 | 如果是 C 端形态，这是真正的"上线日" |

原则不变：**先验证你的 ICP 到底在哪**（访谈里问"你平时在哪看到这类工具"），然后 1–3 个主渠道打深。不要中英双线各铺一遍——单人创始人的注意力只够打好一条线。
