# Metrics：指标、健康线、预算

## 四个早期指标（四个数就够）

| 指标 | 健康线 | 低于健康线说明 |
|---|---|---|
| 访客 → 注册 | 精准流量 <5% 就先修页面，别买量 | 定位/文案/CTA 有问题 |
| 注册 → 激活 | 14 天内 **60%+** 完成核心动作 | 上手引导坏了（最常见的上线后发现） |
| 激活 → 付费 | 免费→付费 **5–10%** 是健康的早期自助基准 | 定价/价值感知/支付 friction |
| NRR（有客户基数后） | **110–120%** | 老客户不扩展，增长全靠新客 |

## 上线后每周看的表

| 指标 | 告诉你什么 | 健康线 |
|---|---|---|
| 激活率 | 注册有没有走到核心价值——上线后第一指标 | 14 天 60%+ |
| Day-7 / Day-30 留存 | 价值有没有重复发生 | 曲线在零上方 flatten |
| Time-to-value | aha 时刻要多久 | 分钟级，不是小时级 |
| 流失率 + 流失原因 | 哪里坏了 / 哪里卖错了 | SMB <5%/月，企业 <2%/月 |
| MRR 增长 | 上面这些有没有变成生意 | 北极星 |
| LTV:CAC | 增长花费能不能成立 | ≥3:1，回本 <12 个月 |

## 单位经济学护栏（第一天就要知道）

- LTV : CAC ≥ **3:1**
- 月流失：SMB **<5%**，企业 **<2%**
- CAC 回本：**<12 个月**
- 如果答不上来"每个付费用户从哪个渠道来"，上线周教不了你任何东西。

## 预算速查

- 精益总盘：**$7K–10K**；宽裕做法：**$20K**；一律 **+30% 缓冲**。
- 付费投放只在漏斗验证后加：$1,000–3,000/月起测，只放量单位经济成立的渠道。
- 定价：B2B 上线甜点 $19–99/月，$29–49 稳妥默认；年付 ≈ 两个月免费（~17%）；**没人抱怨贵 = 定便宜了**（新用户涨价、老用户 grandfather）。

## Rule of 40（自 funded 创始人的定心丸）

**收入增长率 + 利润率 > 40%** 即过关。60% 增长、-20% 利润率过；10% 增长、30% 利润率也过。它给"慢而赚钱"的增长正名：一年 15% 增长 + 30% 利润率，挺好，不用管 hypergrowth 时间表怎么说。

（3-3-2-2-2 增长规则是给 VC scale 公司的年增长率框架，自 funded 创始人当方位参考即可，别当目标。）
